## 已落地

- ONNX Runtime 改为跨平台库查找，去掉硬编码 Windows `.lib`。
- 统一五关键点本地模型类别定义：red→0、blue→2；禁止向同色已命中类别回退。静态读取 ONNX protobuf 元数据确认类别名称和关键点形状。
- 选靶采用几何距离和前目标关联，避免只按置信度不断换叶；新锁使用画面中心距离近似，尚不是带相机标定的光轴夹角排序。
- 空间通道默认每帧 YOLO，失败时返回未检测到，不由 HSV 静默维持旧目标；兼容入口保留 HSV 几何调试用途。
- 修正空间默认 blue 与 HSV 红色范围冲突；红蓝阈值仍需要实验室测量。
- 多个候选扇叶时按 seed 关联；不再把轮廓数增加直接判成命中，未观察到所选目标时失效。更新内部轮廓与半径，关闭调试时不调用 waitKey。
- 相位按最短有符号角差展开，独立处理 2π/5 换叶；不再由颜色决定旋向。断流/倒序重建运动状态。
- 小符增加真实 dt 的标量相位 KF、旋向投票和失效重置；预测像素使用 KF 校正，不只在调试字段中展示。当前 KF 噪声参数为初始工程值，尚未实测标定。
- 大符保留 200 档 ω，同时新增 200 个随机三点候选（固定种子便于复现），对候选内点做最小二乘重拟合；增加病态矩阵拒绝、最小时间跨度、异常观测拒绝与连续拒绝后模型清空。大符速度仍由时间戳差分取得，没有额外速度低通滤波。
- 短时、R 中心位置相近的兼容链路重锁保留转子模型，换叶由相位层处理；明显中心变化或观测时间异常会重置。
- 明确拆分当前观测与未来点，消息携带完整预测时域；空间 Tracker 不重复外推未来点。TF 后重新求角并给出坐标约定。
- PnP 深度有 TTL，超期失效；未来射线和当前观测分别投影。当前 PnP 距离用于本帧时域重算，不再在每个 HSV 帧切回固定距离。
- ROS 帧年龄校验、输入队列保留最新帧、断流定时失效和 LOST 后历史清理。空间工作线程的帧处理异常转换为失效消息。
